# 本機 ↔ 雲端 資料同步

Cloud Agent **讀不到你電腦硬碟**；本機的 `_with_ZE2_` / `_with_a09_` Delsys 必須用 git 推上 GitHub，雲端才能分析。

## 本機把 Delsys（含 with_ZE2）推上去

在本機專案目錄（例如 `C:\Zentan_Rita\測試專案\EMG_compare`）：

```powershell
git checkout cursor/feature-correlation-b6d5
git pull origin cursor/feature-correlation-b6d5

# 確認檔案已放在這裡
# data\delsys\2609-09\2609-09 frank右腓腸肌(Delsys)_with_ZE2_1.csv
# data\delsys\2609-09\2609-09 frank左腓腸肌(Delsys)_with_ZE2_1.csv
# …其他肌群 _with_ZE2_ / _with_a09_ 同理

git add data/delsys/2609-09/
git add data/txt/2609-09/          # 若也有新的 ZE1
git add data/ZE2_txt/2609-09/      # 若也有新的 ZE2
git status
git commit -m "Add 2609-09 Delsys with_ZE2 reference CSVs"
git push origin cursor/feature-correlation-b6d5
```

若 `git add` 沒吃到檔案，強制加入：

```powershell
git add -f "data/delsys/2609-09/*.csv"
```

推完後跟 Cloud Agent 說「重跑」或本機執行：

```powershell
python scripts/run_study_analyses.py --session 2609-09
```

## 雲端結果拉回本機

```powershell
git fetch origin
git checkout cursor/feature-correlation-b6d5
git pull origin cursor/feature-correlation-b6d5
```

結果在：`data\pairing_results\2609-09\`
