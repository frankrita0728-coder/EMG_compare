# 如何把雲端分析結果放到本機

Cloud Agent 無法直接寫入你的電腦硬碟。請用下列任一方式：

## 方式 A：Git 拉取（建議）

在本機專案目錄（例如 `C:\Zentan_Rita\測試專案\EMG_compare`）：

```powershell
git fetch origin
git checkout cursor/feature-correlation-b6d5
git pull origin cursor/feature-correlation-b6d5
```

分析結果會在：

- `data\pairing_results\2609-09\`

資料請放在：

- `data\delsys\2609-09\`
- `data\txt\2609-09\`
- `data\ZE2_txt\2609-09\`

## 方式 B：GitHub 網頁下載

開啟 repo → 分支 `cursor/feature-correlation-b6d5` → 進入 `data/pairing_results/2609-09/` → 下載所需檔案。

## 注意

- `data/delsys/`、`data/txt/` 原始量測檔預設不進 git（`.gitignore`）
- 若本機沒有原始 CSV/TXT，需自行複製進對應資料夾後才能重跑分析
